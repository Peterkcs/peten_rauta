# Results

This folder is empty on purpose. It holds only runs that the group has actually made. Nothing here may be generated by an AI and presented as measured.

## Log a run

1. Create a run file: `python tools/new_run.py results/run-001.md --tool "LehmusAI" --model "model and version" --prompt v1`
2. Paste each test email (copy button on the site, or from `tests/test-emails.json`) into the assistant and paste the answer under the matching `### Txx` heading.
3. Score it: `python tools/score.py results/run-001.md`
4. Open `results/run-001.json` and fill the manual fields for every test: `facts_correct` (true or false, judged against the documents), `invented_facts` (a number), `sendable_after_quick_check` (true or false). Run `score.py` again if you change the run file. The manual fields are kept.
5. Change the prompt or the documents, note the change in `docs/build-log.md`, and make a new run with a new file name. Keep the old run.

Set the targets for each measure before the first run and write them in `docs/build-log.md`.
